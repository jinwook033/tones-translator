# 클로드 디자인 브리핑 — 톤즈 번역 시스템 대시보드

아래 내용을 **그대로 복사해서 클로드 디자인에 붙여넣으세요.**

---

## 붙여넣을 내용 (여기부터)

톤즈의원 내부 번역 시스템의 관리 화면을 디자인해줘.
한국어 원고를 영어·중국어(간체)·대만어(번체)·일본어로 번역하고, 각 언어 원어민이 검수하는 도구야.
쓰는 사람은 병원 마케팅 담당자 1~2명과 언어별 검수자 4명. 하루 종일 보는 업무 화면이야.

### 화면 구성

좌측 사이드바 + 우측 본문. 사이드바 메뉴 6개:
대시보드 / 번역 / 엑셀 일괄 / 검수 / 용어집 / 언어 설정

### 화면 1 — 대시보드 (첫 화면)

가장 위: **검수 대기 현황**. 이 시스템에서 사람 손이 필요한 유일한 지점이라 제일 먼저 보여야 해.
언어별 카드 4개, 각 카드에 대기·수정됨·승인 건수.

    일본어    대기 12   수정됨 3   승인 47
    중국어    대기 8    수정됨 1   승인 52
    대만어    대기 8    수정됨 0   승인 51
    영어      대기 5    수정됨 2   승인 63

그 아래: **바로 손봐야 할 것** — 검증기가 차단한 항목 3~5건.
각 항목에 언어 배지, 한국어 원문, 문제가 된 번역, 오류 코드.

    [일본어] 차단   톤즈의원 이동선 원장 상담
                   Moving line ledger consultation
                   EN_NAME_MOVING_LINE · 사람 이름이 뜻으로 번역됨

    [중국어] 차단   물톡스 3회 패키지
                   水毒素 3次套餐
                   CN_WATER_TOXIN · 직역이 '물 독소'가 됨

오른쪽 또는 아래: **작은 상태 블록 3개**

    용어집     226건        13개 분류
    언어 설정   46개 금지표현  10개 예문
    검증 규칙   60개         4개 언어

### 화면 2 — 번역

왼쪽에 한국어 입력창, 오른쪽에 언어별 결과 카드 4장.
상단에 대상 언어 토글 4개(영어·중국어·대만어·일본어), 문맥 선택(시술명/시술설명/카테고리/일반/약관), 한↔외 방향 전환 버튼.

결과 카드 한 장에 들어갈 것:
- 언어 이름
- 번역 결과 (본문보다 크게)
- 신뢰도 0.00~1.00 (막대 + 숫자)
- 검증 상태 배지 — 통과(초록) / 경고(주황) / 차단(빨강)
- 복사 버튼

예시 데이터:

    원문   톤즈의원 이동선 원장의 리프팅 시술, 150,000원

    영어    Tone's CLINIC Dr. Lee Dong-seon's Lifting Treatment, ₩150,000     0.95  통과
    일본어  トンズ医院 イ・ドンソン院長のリフティング施術、150,000ウォン        0.92  통과
    중국어  Tone's CLINIC 李东善院长的面部提升项目，150,000韩元                0.89  경고
    대만어  Tone's CLINIC 李東善院長的拉提療程，150,000韓元                    0.91  통과

입력창 아래에 작게: **고정된 용어** 칩 — 톤즈의원 · 이동선 · 리프팅

### 화면 3 — 엑셀 일괄

파일 올리는 영역, 그 아래 진행 막대.
진행 중일 때: `142 / 380 번역 완료`, 누적 토큰과 예상 비용.
끝나면 언어별 다운로드 버튼 4개.

중간에 **미등록 용어 경고** 상태도 필요해 — "용어집에 없는 단어 7개를 찾았습니다" 목록과 각각 저장 버튼.

### 화면 4 — 검수 (가장 중요)

언어 탭 4개(대기 건수 배지 포함) + 필터(상태, 검증기가 잡은 것만, 검색).

세로로 쌓이는 카드 목록. 카드 한 장:
- 왼쪽에 색 띠 — 차단 빨강 / 경고 주황 / 정상 초록
- 상단 줄: 문맥 태그, 상태 배지(검수 대기/수정됨/승인), 신뢰도
- 원문 (한국어)
- 모델 번역 (흐리게)
- 검증기 지적 사항 (있으면)
- **고칠 수 있는 입력창** — 여기가 제일 커야 해
- 버튼 4개: 수정 저장 / 이대로 승인 / 검수 취소 / 이 수정을 예문으로

예시 카드:

    [차단]  시술설명 · 검수 대기 · 신뢰도 0.41

    원문      톤즈의원 원장이 직접 진행하는 이마 주름 시술입니다.
    모델 번역  トンズ医院院長が直接担当する、おでこのしわ施術です。
    지적      JA_ADMIN_TANTOU · 担当는 사무적 표현 → 施術
    고치기    [ トンズ医院 院長が自ら施術いたします。…              ]

### 화면 5 — 용어집

검색창 + 표. 열: 한국어 / 분류 / English / 简体 / 繁體 / 日本語 / 고정 / 삭제.
분류는 `procedure (시술명)`처럼 영문 코드와 한글을 같이 보여줘.

분류별 건수 (실제 값):

    equipment 장비구성 60   procedure 시술명 30   device 의료기기 24
    product 제품명 21      location 지점·지명 21   category 시술카테고리 15
    anatomy 신체부위 14    person 인명 13        menu 사이트메뉴 7
    condition 증상 7       general 일반용어 6     tag UI태그 4   brand 브랜드 4

### 화면 6 — 언어 설정

언어 탭 4개. 각 언어마다 세 덩어리:
- 문체·표기 규칙 (긴 텍스트 입력창)
- 절대 나오면 안 되는 표현 (한 줄씩 추가·삭제)
- 대조 예문 (원문 / 이렇게 나오면 안 됨 / 이렇게 나와야 함 / 이유, 네 칸)

실제 개수: 영어 금지표현 10·예문 3 / 중국어 13·2 / 대만어 11·2 / 일본어 9·2

### 디자인 요구

- **다크 테마.** 배경 거의 검정, 카드는 한 단계 밝은 회색
- 강조색은 형광 연두 계열 하나만. 나머지는 무채색
- 상태색은 강조색과 별개로: 통과 초록, 경고 주황, 차단 빨강
- 한국어·영어·중국어·일본어가 한 화면에 섞이니 **네 언어가 모두 읽히는 글꼴**로
- 숫자는 자릿수 맞춰 정렬
- 데스크톱 기준 1280px 이상. 하루 종일 보는 업무 화면이라 화려함보다 **오래 봐도 안 피로한 것**이 우선
- 빈 상태도 그려줘 — 검수할 게 없을 때, 번역 결과가 아직 없을 때
