# 디자인 → 구현 매핑

`Tones Translation Console.dc.html` 를 실제 화면으로 옮길 때 참고하는 문서.
디자인 파일은 클로드 디자인 캔버스 결과물이고, 자체 상태를 가진 동작하는 시안이다.

---

## 1. 디자인이 정한 것

### 토큰 — `.dc.html` 안의 `:root`

디자인 시스템(`_ds/nocturne-.../styles.css`)이 같이 왔지만, **시안은 자기 토큰을 따로 정의해서 쓴다.**
구현할 때는 `.dc.html` 의 `:root` 를 따른다.

```css
--bg:#0f111b        --surface:#191c28    --surface2:#141724   --raise:#20242f
--line:rgba(233,233,237,.10)             --line2:rgba(233,233,237,.18)
--txt:#e9e9ed       --muted:#9397ab      --dim:#75798c
--accent:#c4f24d    --accent-ink:#15170f --accent-soft:rgba(196,242,77,.12)
--ok:#57c98b        --warn:#e2a247       --bad:#e2655f
```

강조색은 형광 연두 하나. 상태색(`ok`/`warn`/`bad`)은 강조색과 별개.

### 글꼴 — 언어별로 다르다

```css
--fnt: "Inter","Noto Sans KR"      기본
--ja:  "Inter","Noto Sans JP"      일본어 출력
--sc:  "Inter","Noto Sans SC"      중국어 간체
--tc:  "Inter","Noto Sans TC"      대만어 번체
```

번역 결과를 찍을 때 **언어에 맞는 글꼴 변수를 줘야 한다.** 한 글꼴로 4개 언어를 찍으면 한자 모양이 언어별 관례와 어긋난다.

### 레이아웃

- 좌측 사이드바 **212px** 고정 + 우측 본문
- 최소 폭 **1280px** — 반응형 아님, 데스크톱 전용
- 상단 헤더에 화면 제목·부제, 우측에 「빈 상태 보기」 토글과 마지막 동기화 시각

### 아이콘

Phosphor icons. 시안은 unpkg CDN 을 쓰지만 **구현에서는 npm 패키지를 설치**한다.

```bash
npm i @phosphor-icons/web
```

## 2. 화면 6개 → 기존 API

시안의 `sc-if` 블록 순서 그대로다.

| # | 화면 | 시안 위치 | 쓰는 API | 상태 |
|---|---|---|---|---|
| 1 | 대시보드 | 83행 `isDash` | `GET /review`(stats) · `GET /glossary` · `GET /language` | **신규 화면** |
| 2 | 번역 | 167행 `isTrans` | `POST /translate` | 기존 텍스트 탭 |
| 3 | 엑셀 일괄 | 240행 `isExcel` | `POST /translate-excel-stream` (SSE) · `POST /search-term` | 기존 엑셀 탭 |
| 4 | 검수 | 311행 `isReview` | `GET·PUT·POST /review` | 기존 검수 화면 |
| 5 | 용어집 | 390행 `isGloss` | `GET·POST·PUT·DELETE /glossary` | 기존 용어집 |
| 6 | 언어 설정 | 432행 `isLangSet` | `GET·PUT·DELETE /language` | 기존 언어 설정 |

2~6번은 이미 API가 다 있다. **화면만 새로 그리면 된다.**

## 3. 시안의 숫자 — 실제와 대조

시안에 박힌 값 중 **실제와 다른 것이 있다.** 구현할 때 API 값으로 채워야 한다.

| 시안 표시 | 시안 값 | 실제 값 | 판정 |
|---|---|---|---|
| 용어집 건수 | 226건 | **226건** | 맞음 |
| 용어집 분류 | 13개 분류 | **13개** | 맞음 |
| 용어집 「고정 용어 41건」 | 41 | `locked:true` **130건** / 치환 대상 **201건** | **틀림 — 근거 없는 값** |
| 금지표현 | 46개 | **46개** (en10·cn13·tw11·ja9·ko3) | 맞음 |
| 대조 예문 | 10개 | **10개** | 맞음 |
| 검증 규칙 총계 | 60개 | **60개** | 맞음 |
| 검증 규칙 「차단 22 / 경고 38」 | 22 / 38 | **차단 51 / 경고 9** | **틀림 — 뒤집혀 있음** |
| 검수 대기 건수 | 언어별 값 | 실운영 데이터 없음 | 예시 (의도된 것) |
| 엑셀 예상 비용 ₩3,140 | 3,140원 | 150건 기준 실측 추정 **약 7,000원** | 낮게 잡힘 |

「차단 22 / 경고 38」은 실제로 **차단이 압도적으로 많다**(51 vs 9). 이 시스템은 애매하면 경고가 아니라 차단을 거는 쪽으로 만들어져 있다. 대시보드에서 이 비율이 뒤집혀 보이면 운영 판단을 잘못하게 된다.

비용은 실측 기준이 다음과 같다 (4개 언어 동시, Sonnet 4.6):

| | 첫 호출(캐시 없음) | 캐시 적중 |
|---|---|---|
| 시술명 | 110원 | 26원 |
| 시술설명 | 160원 | 63원 |

## 4. 시안에 있지만 아직 데이터가 없는 것

| 시안 요소 | 필요한 것 |
|---|---|
| 「마지막 동기화 09-17 14:22」 | 동기화 시각 기록 |
| 「마케팅 · 김세영」 사용자 | 로그인 없음 — 고정 문구로 두거나 제거 |
| 강조색 전환(lime / blurple) | 시안 전용 기능. 구현에 넣을지 결정 |
| 이번 달 누적 비용 | 작업 기록이 없음 — 남기는 것부터 만들어야 함 |

---

## 5. 작업 순서

1. **공통 껍데기** — 사이드바 212px + 헤더 + 토큰 + 언어별 글꼴
2. **화면 2·4** (번역 · 검수) — 가장 많이 쓰는 두 화면
3. **화면 5·6** (용어집 · 언어 설정) — 기존 화면을 시안에 맞춰 갈아끼움
4. **화면 3** (엑셀) — SSE 진행률이 붙어 있어 손이 더 감
5. **화면 1** (대시보드) — 나머지가 다 돌아야 의미 있는 숫자가 모임

기존 `app/translator/page.tsx` 692줄은 2·3번으로 쪼개면서 버린다.
